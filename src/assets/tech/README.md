# Technology icons

Logos for the tools on the Work and Skills sections, and the Contact links, kept here as SVGs so they never depend on an outside link. `src/components/TechIcon.astro` draws them in the text colour (any colour in the file is ignored) and maps tool names to files (`TECH`).

- [Simple Icons](https://simpleicons.org/) 16.36.0, CC0 1.0: Astro, Claude (Claude Code), CSS, Cursor, Dart, Docker, .NET, Express, Figma, Flutter, Git, GitHub, GitHub Copilot, Google Search Console, GSAP, HTML5, JavaScript, MariaDB, MySQL, Next.js, Node.js, PHP, PostgreSQL, Python, Qt (PyQt), React, Rust, Sanity, Spring Boot, Squarespace, Tailwind CSS, Tauri, TypeScript.
- [Devicon](https://devicon.dev/) 2.18.0, MIT (© 2015 konpa): C# (`csharp`), Codex, Illustrator (line), Java, LinkedIn, Playwright.
- VS Code (`vscode.svg`) and Email (`mail.svg`): the `vscode` and `mail` icons from Microsoft's [Codicons](https://github.com/microsoft/vscode-codicons) 0.0.46, CC BY 4.0 (© Microsoft Corporation).

The logos themselves are trademarks of their owners. To add one, copy its single-colour SVG here and add it to `TECH` in `TechIcon.astro`.
