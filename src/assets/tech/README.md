# Technology icons

Brand icons for the tools shown on the Work section's rows, from [Simple Icons](https://simpleicons.org/) 16.36.0 (CC0 1.0). The logos themselves are trademarks of their owners; Simple Icons' disclaimer applies. Add one by copying `icons/<slug>.svg` from the `simple-icons` package here and adding it to `TECH` in `src/components/TechIcon.astro`.
